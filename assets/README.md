# assets/ — 标识与社交预览图

## 里面是什么

| 文件 | 是什么 |
|---|---|
| `logo.svg` | 项目标识。纯几何，64×64 viewBox，不含文字 |
| `social-card.html` | GitHub 社交预览图的**源文件**（1280×640） |

**没有 PNG。** 仓库根的 `.gitignore` 忽略 `*.png`（那条规则是为了拦住简历照片），
而 `tools/security_guards.py` 只允许一条既有的例外。为了一张图去放宽个人数据守卫，
不划算——PNG 在本机渲染、直接上传，不进版本库。

## 标识：四态方章

它不是新造的。`web/src/components/GateStamp.tsx` 里那个「硬性条件四态方章」
才是这个项目的签名元素，标识是把它抬起来：

```
┌───┬───┐    左上 实心青  = 过（满足）
│▓▓▓│▒▒▒│    右上 斜纹红  = 否（不满足）
├───┼───┤    左下 空心琥珀 = 疑（还没查到）
│ ◇ │ ┈ │    右下 虚线灰  = 无（不涉及）
└───┴───┘
```

一枚章被十字切成四格 —— **一个对象，不是四块砖**。这个区别是有意的：
四个等重的实心色块会读成应用启动器（离微软那个太近），而「一格实心 + 三格不同形制」
读起来是一张**判定图例**。

三条约束都来自项目自己，不是外加的：

- **零圆角**。`tokens.ts` 写着理由：「这个项目的核心动作是「盖章 / 判定」，
  方形是它的形制语言。」
- **形制先于颜色**。四态靠实心／斜纹／空心／虚线区分，所以色盲可辨，
  缩到 16px 颜色失效时也仍分得出四个明度层级（16/32 两档都实渲过）。
- **色值逐字取自 `palette`**，`tests/test_contrast.py` 验过对比度。标识与产品
  长得不一样，是最容易发生也最没必要的分叉。

标识里**没有字形**，所以在任何缺中文字体的机器上都不会碎。

## 社交预览图：主视觉是一次判定，不是一句标语

每个求职工具都说自己「帮你找到工作」。这个工具真正做的是**替你说「不」**——
带着理由。所以卡上放的是产品最有主张的那一刻：三行岗位，两行被硬性条件刷掉、
分数栏是「—」不是 0，一行亮着。

台面上那行读数（抓到 63 ／ 刷掉 41 ／ 打分 22 ／ 可以投 9）每个数都推得出来。
**只有数字用等宽**，中文一律比例字体 —— 这是 `AGENTS.md` 的排版规矩
（等宽加大字距只适用于拉丁文，中文套上去会被拉成散字），在这里变成一个看得见的决定。

## 怎么渲染

用 `html-shot`（Playwright + 系统中文字体，不必打包字体）：

```bash
SK=~/.claude/skills/html-shot
node $SK/render.mjs assets/social-card.html /tmp/social-card.png --palette
```

`--palette` 把平面图形量化到 256 色，体积降到三分之一，肉眼无差别。
产物 1280×640，正好是 GitHub 社交预览的尺寸。

标识要出成位图时（比如做 favicon）：

```bash
node $SK/render.mjs assets/logo.svg /tmp/logo-512.png --width 512 --transparent
```

> ⚠️ `social-card.html` 的 `<html lang="zh-CN">` 不能删。CJK 字形回退跟着它走，
> 缺了它在非中文环境的机器上会渲出日文字形。

## 怎么用上

**社交预览图**：仓库 → Settings → General → Social preview → Upload an image。
只能手工传，`gh` CLI 没有这个接口。改了 `social-card.html` 就重渲一次再传一次。

**标识**：`assets/logo.svg` 可以直接嵌 README 或别处。目前**没有**放进 README 页头——
这个仓库有意去掉了上游的吉祥物页头（见 `tests/test_readme_assets.py` 的说明），
要加回去是个决定，不是顺手改。
